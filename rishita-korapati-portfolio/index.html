    Featured · Risk & credit

    Explainable Credit Default Risk Engine

    Python · Logistic regression · XGBoost · SHAP · FastAPI · Streamlit

    A default model built to be accurate and defensible. Trained on 30,000 real, anonymized credit card records (UCI), calibrated with isotonic regression, checked for fairness across 4 demographic dimensions with the four-fifths rule, and served through an API and dashboard with SHAP explanations. A 10-test suite covers leakage, calibration and fairness.

    ROC-AUC 0.749 → 0.777
    Brier score, lower is better 0.179 → 0.135
